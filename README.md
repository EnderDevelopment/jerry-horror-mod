# Jerry Horror Mod

A Fabric mod for Minecraft with horror elements inspired by LookOut2DD's Jerry storyline.

## Features

- Jerry entity with stages of aggression
- Unpredictable appearances and disturbing animations/sounds

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/jerry-horror-mod/releases).
2. Place the downloaded JAR file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

Once installed, the Jerry entity will spawn naturally in the game world. Players can encounter Jerry, which will have different stages of aggression and unpredictable behaviors.

## Configuration

The mod does not currently support configuration files. Future updates may include additional settings for customization.
